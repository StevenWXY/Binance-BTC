# 六路线统一回测

六组均使用 `D:\文档\桌面\data.zip`，区间 `2020-01-01` 至 `2026-08-01` UTC，初始资金 `10,000 USDT`。每个策略分别运行关闭和启用回撤管控两种版本。

统一执行条件：4h 信号、1m 成交/标记价格、资金费；taker 4 bps、基础滑点 1 bps、冲击 8 bps、每分钟最大市场参与率 2%、强平费 50 bps。2% 是订单相对于当分钟市场成交额的流动性上限，不是目标仓位上限。

回撤管控对所有策略使用同一组独立 Governor：回撤 8%/12%/16% 时目标仓位缩放为 0.80/0.50/0.00。关闭组只关闭 Governor，策略信号和全局 2% 流动性限制不变。

## 策略和参数

- **V4.3**：V4.1 趋势/反弹框架，支持 maker 常规调仓、ATR 止损/止盈、跟踪止损和快速下跌保护。参数：`configs/v4_3_params.json`。
- **V7.1**：互斥 `range/trend_up/trend_down` 状态机，日线门控、4h 趋势确认、Donchian 突破、ATR 风险仓位和对称空头。参数：`configs/v71_params.json`。
- **V7.2**：V7.1 live engine 的增强版，增加 long 初始确认、连续趋势加仓、short 初始确认、强趋势保护和止盈放宽。参数：`configs/wzy_v72_tp_refined_params.json`。

## 结论

不启用 Governor 时，V7.1 的历史收益最高，但最大回撤达到 `-46.56%`；启用同一套 Governor 后，V7.1 回撤降至 `-14.18%`，但收益显著下降。V4.3 和 V7.2 也表现出相同方向：回撤管控降低风险和杠杆，同时牺牲收益。六组结果应理解为风险开关敏感性分析，不代表未来收益保证。
