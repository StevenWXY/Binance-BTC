风险层先将 V4.5.3 目标暴露缩放至 25%；月内 BTC 收盘价相对月初下跌 5%/10% 时缩放至 50%/20%，月内上涨 6% 后缩放至 25%。
这是一项因果风险预算：当前完成小时计算，下一小时执行。月度稳定性来自风险控制和暴露收缩，不应解释成新增 alpha。
