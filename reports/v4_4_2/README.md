# V4.4.2

V4.4.2 是原 **V4.4.1-R2** 的正式版本名称，策略逻辑和冻结结果保持不变。它采用中速 4h 核心、小时趋势恢复入场、3 ATR 初始/跟踪保护、72 小时最长持仓和 4 倍上限。

在 40% Taker 返佣（有效费率 2.4 bps）下，2024-01 至 2026-07 的 1 分钟成交回测为 **158.84% 累计收益、1.088 日收益夏普、22.75% 最大回撤、130 个完整周期**。完整研究过程和原始无返佣 R2 结果仍保留在 [`../v4_4_1_round2/README.md`](../v4_4_1_round2/README.md)。

V4.4.3 在 V4.4.2 基础上增加了频率与保护网格，见 [`../v4_4_3/README.md`](../v4_4_3/README.md)。
